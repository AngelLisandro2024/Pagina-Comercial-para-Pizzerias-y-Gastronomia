# 🍕 Plantilla Landing Page para Pizzerías y Gastronomía (Bootstrap 5)

Sitio web estático, responsivo y de alto impacto visual diseñado como plantilla base para pizzerías, restaurantes o emprendimientos gastronómicos. Su diseño está optimizado para mostrar la oferta del negocio y acelerar las ventas mediante enlaces directos a WhatsApp y llamadas telefónicas.

---

## ✨ Características Principales

* **🎠 Hero Section con Carrusel:** Banner dinámico principal para promocionar especialidades, ofertas de temporada o instalaciones.
* **📱 Diseño 100% Responsivo:** Maquetado responsivo basado en el sistema de rejilla de **Bootstrap 5.3.3**, adaptable a celulares, tablets y escritorios.
* **🖼️ Galería con Visor Modal:** Galería interactiva dinamizada con JavaScript (ES6) que permite expandir cualquier imagen a pantalla completa al hacer clic.
* **📲 Pedidos Directos por WhatsApp:** Botones de llamada a la acción (CTA) vinculados a la API de WhatsApp (`wa.me`) con mensajes predefinidos.
* **📍 Sección de Ubicación y Horarios:** Módulo con dirección del local, horarios de atención e integración directa a Google Maps.
* **🛠️ Código Guiado:** HTML comentado paso a paso para modificar rápidamente textos, imágenes, precios y datos de contacto.

---

## 🛠️ Stack Tecnológico

* **Estructura:** HTML5 Semántico
* **Estilos:** CSS3 (Variables nativas `:root` + Flexbox) / Bootstrap 5.3.3
* **Iconografía:** Bootstrap Icons 1.11.3
* **Lógica Client-Side:** JavaScript (ES6) para la gestión del visor modal y el año dinámico del pie de página
* **Hosting / Despliegue:** GitHub Pages
